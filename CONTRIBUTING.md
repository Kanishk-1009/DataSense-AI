# Contributing to Smart Dataset Understanding Agent

Thank you for your interest in contributing!

We welcome contributions from developers, researchers, and students.

---

## Getting Started

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/YOUR_USERNAME/smart-dataset-understanding-agent.git
```

3. Install dependencies.

Backend:

```bash
cd backend
pip install -r requirements.txt
```

Frontend:

```bash
cd frontend
npm install
```

---

## Create a Branch

Always create a new branch.

```bash
git checkout -b feature/your-feature-name
```

Example:

```bash
git checkout -b feature/dataset-health-score
```

---

## Coding Standards

### Python

- Follow PEP8
- Add docstrings
- Use meaningful variable names
- Keep functions modular

### React

- Functional Components
- Hooks
- Tailwind CSS
- Keep components reusable

---

## Before Submitting

Make sure:

- Code builds successfully
- No syntax errors
- No unnecessary files
- .env is NOT committed
- node_modules is NOT committed

---

## Commit Messages

Examples:

```
Added Missing Value Agent

Implemented Dataset Profiling

Improved Dashboard UI

Fixed CSV validation
```

---

## Pull Requests

Include:

- Description
- Screenshots (if UI changed)
- Steps to test
- Related issue number

---

## Reporting Bugs

Open a GitHub Issue including:

- Expected behavior
- Actual behavior
- Steps to reproduce
- Screenshots
- Operating system
- Python version
